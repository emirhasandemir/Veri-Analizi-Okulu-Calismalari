# 📊 Veri Analizi ve Yapay Zekâ Müfredat Çalışmaları

## ⚙️ Teknik İçerik ve Müfredat Kapsamı
Eğitim modülü kapsamında Google Colab bulut ortamı üzerinde aşağıdaki kütüphaneler ve algoritmalar aktif olarak deneyimlenmiştir:
* **Veri Manipülasyonu & Analizi:** Python, Pandas, NumPy
* **Veri Görselleştirme:** Matplotlib
* **Boyut Azaltma Modelleri (Unsupervised):** PCA (Principal Component Analysis)
* **Gözetimli Öğrenme & Sınıflandırma:** SVM (Support Vector Machine), LDA (Linear Discriminant Analysis)
